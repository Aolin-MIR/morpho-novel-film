# 影像创作方法

以角色此刻的目标、场面中原本成立的规则和观众将发现的证据为起点。方法库在 [catalog.json](references/catalog.json)，可按名称、剧情线索、所需底片和当前能力检索。在 Morpho 项目中，项目根目录的 `scripts/film_art_routes.py` 按 `art.cues` 筛选目录候选；它不代替试片验证。在镜头单的 `art` 写明 `cues` 和 `methods`，每个选中的条目附本镜可见执行。提交到队列时校验并写入制作台。正在制作的旧版按既有授权继续，应用新方法时写明影片与版本。

在带 H3 底片的拍摄单里，用 `art.capture` 按目录编号或已审条目的机制 ID 填写演员和摄影能完成的动作，派单会把它编入本镜实际提示。把后期的活字、音乐提前点、材质变化留在 `art.methods` 的完整执行说明和相应合成工程里。用原片核对谁动、朝哪儿、手里拿什么，再在时间线上确认手法生效。

## 方法库的组织

把可执行、可复验的方法作为登记和选用的单位。风格可表达创作意图或作非互斥分类，一种风格可以调用多种方法，一种方法也可用于多种风格。每种方法可以积累多部试片及其修前、修后证据，试片共用本技能。按 [方法边界与实例](references/selection-guide.md#方法边界与实例) 判断何时新增方法。[目录分类](references/style-method-map.json) 保留原 80 项，含 19 个艺术风格、33 个表达方向和 28 个具体手法。

## 为当前剧情选用已审方法

先读 [选用与迁移](references/selection-guide.md)。按本镜观众要得到的新信息检索 [已审方法](references/verified-methods.json)，不要仅按喜欢的风格或小说名套用。可运行本 skill 的 `scripts/select_verified_methods.py --help`，用剧情需求或已登记的表达方向缩小候选。地点或主题未命中时，先改写为观众要看见的事，再按本镜已确认条件检索；仍无匹配时保留空结果。

已审机制以条目 `id` 作为 `art.methods` 的键，把确认成立的 `required_conditions[].key` 写进 `art.cues`，不要拿理论编目编号代替机制 ID。项目派单会核对条件、冲突、制作路径并携带证据；可拍动作写入 `art.capture`。`production=cpu-edit` 的方法在后期按实剪来源与时间线执行，不能直接派成 H3 拍摄合同。
候选的成立条件逐项映射到本镜的实际人物、物件、光源、遮挡与动作，注明尚未满足项。未建立条件先补镜头或改选方法；不要靠标题、字幕或提示词替画面证明效果。候选记录的 `single-scene-tested` 只表示具体试片已经审看，迁移到新书、新场景或不同光位仍须复验。

每次新试或返修后，用原片时码记录实际结果、适用范围和失效条件。独立看片通过且在场面中产生预期作用的产物，才增加或更新已审条目。用户认可记录与独立看片记录分开；不能把用户对某轮的认可外推到未看的新片。每个候选只承诺画面证实的动作阶段，下一镜需要完成的认人、交接、开门或逃离须另行拍摄与验证。

## 视觉表现力试片

接到奇异、新奇或视觉震撼的要求时，选镜和派单前读 [视觉表现力的设计与审看](references/visual-impact.md)。先把全幅画面构想和主关系的变化编入分镜、参考职责与实际制作提示，再按同一目标查看母版和手机尺寸成片。工艺、视觉读法和迁移证据分别登记。

## 从一处返修改进其他镜头

遇到效果抢过表演，先把演员、空间和声源恢复到同一条可读因果。把效果当成回应真实动作的变化，明确哪个实物先存在、哪一下接触触发、哪些对象必须原样留在画面、接下来谁改变做法。取字用同一演员的视线、肩、肘、腕和自然比例。碑、杯、水、光线与剪辑也用同样原理，跟实物和运动做对位，保住受力、遮挡、尺度、主光方向与声音所在。复杂美学从可信的物理与表演中生长。

先把意图写成观众在看片时会读到的变化，例如「她拿回对自己的描述权」。预先分清有意打破的约定和仍要成立的约定。字幕可以进入场内；角色的身份、身体、光向与前后动作仍须成立。当地理、尺度、时间或声音故意改变时，先让观众认得基准，再看得到触发，最后看得到后果。位置、因果、人物选择和情绪有冲突时，优先恢复希望观众读出的意思。

只看效果越清楚，往往越容易把目标认错。局部优化（字更大、光更亮、话念更重、切得更快）要以邻镜和段落为尺度复核。看片时先遮住制作说明，试答「谁动了、为什么、改变了什么、我该感到什么」。手法和答案不一致时，收回效果、换成同一底片上的真实交互，或重编触发和后果。需要超现实尺度本身产生意义时，先给足参照、反应和回收。

先单看触发动作，再连看前后镜。人物身份或比例失真、实物跳位、效果遮住剧情证据、声音拖沓，记录具体发生时刻。优先缩小改动到实际出错层，材质、景深、配色和构图继续继承全片设计。

- 故障艺术仅在荒诞影片或已经建立可辨形式的段落选用。规划必须包含风格、铺垫、触发、视觉规律及后果。单有屏幕、闪烁或跳帧证据不能通过。试剪邀请观看者在无说明时辨认手法和结果。
- 叙事越界先建立谁有权写字幕、说旁白或决定画框。把跨越写成角色的一个具体行动，保留接触、遮挡和越界后的可读结果。优先考虑握走一个词、把字幕带进场内、打开画幅或拒绝上一层画外命令。用前后两镜确认新规则改变了行动。
- 空间主义先给观众一个可以辨认的平面和方向。由人物动作造成的切口必须显露同一镜原先看不见的内容，并改变判断或行动。已有对位的二维素材足以做到局部揭示。
- 适合时可以叠加几种方法。正常表演、道具接触和完整对白保持可读。没有叙事触发就保持有效的表演和空镜节奏。
- 三维待接条目保留提案。使用二维遮罩、剪辑、现场声、H3 表演和已验证程序素材中的可用技术。


当两个镜头看似接得上，先从上镜最后可辨的一刻读出道具持有人、运动阶段、遮挡和观众注意点，再按这些条件从下镜找第一个能用的动作。换人持物要见到交接或已建立的省略线索；同一动作从第二机位接入时避免重新起手。现场确实只拍到结果时，剪辑和导演字幕都只能描述看得见的结果。断续、夸张、错位可以是作者的选择，需在片中给出观众能区分故意与偶然的线索。

返修经验由 DSW Agent 的 `record-case` 登记原片、发生时刻、观察和决定。涉及跨书迁移时，记录与 `repair-plan` 使用相同的 `failure_modes`，如道具易主 `prop-custody`、缺少受力或到位阶段 `lost-action-phase`、重复起手 `repeated-action-phase`、特效早于接触 `contact-timing`。外片案例只提供检查方法。人物、道具、镜长以及是否重拍都按当前影片的实际素材决定。修复前的退件与已看过的修复结果分开记。

每个实际制作记录需要项目、镜头、原片或程序资产指纹、角色选择、适用方法、执行提示、触发时刻、可见后果和审看状态。只在产物已存在，且方法在画面里真的生效时将其登记为已制作；是否采用由实剪证据确认。

## 从试片标注复验手法

每轮制作或替换试片前，读取审片页 `/api/review-films/studies` 中的 `annotation.issue` 和场景/穿帮标注，把用户原文连同对应试片、母版及时码归入本轮问题。独立审看片先只看媒体，再对照用户反馈；主审按可复验的问题定点修订。保存的问题不因替换视频而清空，不把旧问题未经复核套给新版。
收到「容易看成穿帮」时，先定格可疑变化前后，指出观众原本依赖哪项连续性、画面给了什么触发。按 [审片对照与适用范围](references/method-review.md) 做一项有对照的修订或新试，不把未通过验证的镜头推荐为方法。保存试片版本、时码、观察和适用场景，能复验的方法才进入目录的「当前可用」。

## 长片拍摄前的连续性预检

按场登记仍在画面中起作用的对象。参考图要有单一职责。远景供地理和比例，认人与表情用原生中近景。场景与道具参考从无人物的画面或裁切区选，人物参考用原像素脸框核验。光变可以改变反光和阴影。布料本色、裁剪层次和道具身份的变化需要镜内原因。

用 `scripts/dispatch_dsw_film_batch.py --preflight --require-continuity` 预检新批次。说明每镜接过哪个观众问题、提供什么可见的新证据。先排实际动作与说话顺序，表演有节奏变化但不会为镜长重说重做。新增视觉效果需要起因、承载面、时限与可见后果，H3 拍干净表演和实际触发，后期层做精确变化。

从已确认的上一镜末端选交接帧，并用同一组身份、道具、光位继续。两个独立生成镜可能各自可用却无法相接。画内原声、话外音、环境和拟音以真实母版时码排入，原生对白按音、口型和说话者分别检查。旁白避开可见说话，环境有动机地接镜，配乐及拟音分轨让位。

八部长、短片的完整路线和引用见项目内的 `docs/film-continuity-production-zh.md`。

### 宣传片的冲突与声场

前三秒给观众能看见或听见的冲突。先确定谁想要什么、眼前的阻挡和失败会失去什么。靠可见证据、人的行动和处境改变形成戏剧升级。给动作转折留重音和一拍后果，判断观众能否只凭成片看懂。

前三秒可以让画外的具体声源先行，然后由镜头交代声源。撞击、纸张、风、门和机械声要符合片中物体、方向及空间。使用低频、近处接触和远处环境形成层次。配乐、拟音和呼吸声的出入点按动作定，张力和密度随段落变化。同期话语完整可听，旁白只在有空间时说出画面之外的信息。

### 镜头提示与连续性复验

在台本、分镜、首帧、视频之间传递同一个可见对象及其入出状态。新写台本用 SceneWeave 2.0 的连续性锚点记录动作触发。分镜对照编号和台词位置。同一事件下一拍逐字承接已有状态。片级配色、象征和声音策略留给导演表，模型只接到本镜实际出现的主体、材质、地标、发声者和动作。仅在当前镜头确有该变化时写触发位置、承载面与后果。

每个参考只锁它能清楚提供的属性。袖口图只管面料和裁剪，非人角色的体形图只管比例和轮廓，地点图只管地理及光向。用自己的提示词和本场已确认参考作为生产输入，旧镜用实际提交回执核对。先把受力、接触、动作结束和接镜作为判断项，再拉片检查。生成失败时先定位是提示歧义、参考图串入、模型动作失败还是剪切错误。

比较新旧提示时锁模型工作流、原始参考、种子、画幅和镜长。先凭画面看同一主体、接触动作和结果，再查实际请求及回传。模型改了触点、提前松手或让同一物件在遮挡后跳位时保留反例。单例结果按实际改善项记录。
