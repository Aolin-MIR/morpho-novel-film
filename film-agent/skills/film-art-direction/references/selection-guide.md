# 已审方法的选用与迁移

用于分镜、拍摄或修片时，先写出本镜要解决的观众问题，以及角色得到信息后采取的动作。已审方法记录在 verified-methods.json；catalog.json 的“当前可用”仅代表制作路径存在，不能代替具体镜头的审看证据。

## 方法边界与实例

- 按影视手法如何改变观众阅读，以及维持该变化的必要条件，判断条目边界。机制或必要条件有实质变化时新增方法。只换作品、场景、人物、道具或材料时，沿用同一方法并补记时码、结果与限制。把修前失败和修后结果挂在同一方法下。
- 迁移时可调整题材、场景尺度、材质、机位或镜长。核对现有底片、空间与时间基准、触发、信息可读性和后镜责任，尤其留意遮挡、连续性或误读会在哪一步让手法失效。
- **崇高感可由不同方法实现。**「近窗尺度与天候巨景」借固定近景和稳定远景建立大小与距离，可迁移到峡谷或巨构，推进切掉远景锚点时失效。「逐区照明揭出巨构纵深」靠分区灯依次显出既有结构，可用于仓库、洞室或设施，灯变时结构移位就破坏空间连续。
- **图形匹配可以用多次试剪验证。**「在切口匹配形位再揭示新对象」首版切到锯齿刻痕，匹配未成立。返修在母版 2.5 秒从风暴眼切到近似位置和尺度的螺钉头，再拉宽交代物件。跨场、跨材料都可试用，切点需让两个主形清楚可比，剪辑本身只能建立画面联想。
- 审片页的方法标签优先显示具体手法名称，如「逐区照明揭出巨构纵深」。已有的风格称谓用于辅助理解创作意图，照明、景别和剪辑技术直接用其名称。

[80 项目录分类](style-method-map.json) 中的 `verified_method_ids` 只列已审条目实际引用的编号关系。一个局部手法的试片只支持该手法的已审范围。已审方法的表达方向、分类状态和依据取自相应试片的审片记录。

## 检索方式

选择器按词表精确匹配。用 `--list` 查看方法的表达方向、分类状态、条件键和别名，再用 `--need 凝露` 或 `--need 主观感知` 缩小候选。多个 `--need` 取交集。`--conditions` 只填本镜已确认的条件。表达方向可以参与检索，派单仍逐项核对镜头条件和画面执行。

例如，--need 凝露 --conditions 起雾玻璃 --conditions 手边有布 仅确认表面与工具；是否起幅仍遮住目标信息、清晰区是否紧跟接触路径，仍在输出的未满足项中。发现后的动作随剧情另行核对。空候选不代表技术上永远不可做；它表示本库没有满足这组检索的已审证据。未识别词不会自动批准或自动排除；agent 必须阅读候选全文，对照这些额外约束作出判断。存在冲突的条目单独列出，不作可选候选。

地点和主题词未命中时，先写清「原先看不到什么，哪一下变化让观众发现什么」。例如 `--need 候车厅 --need 等待` 可查不到候选。若剧情要表现等人者在行李车移开时发现对面的人，改查 `--need 遮挡揭示`，核对遮挡后是否持续显露、远处目标是否有稳定辨识点。若要表现等待的主观感受，先说明哪一种环境运动或节奏变化能让观众感到时间拉长。

用机制范围、可调参数和常见场景构思迁移。按必需条件和失效条件筛选，再用证据字段核对具体试片、时码与可见结果。新场景仍须实拍或生成后复验。

证据路径以 Morpho 项目根目录为基准。DSW agent 可从已发布库按 evidence.study_id 找母版或访问 evidence.playback；先与 master_sha256 核对。原片与母版有裁切、裁时差异，超出母版的原片时码不能据网页复验；缺少对应媒体时明确标为未复验。

使用 CPU 剪辑条目时，从 evidence.sources 核对各原片 SHA-256、帧率和可用帧域，再从 edit_timeline 对照母版取段。evidence.timebase 说明观察时码属于原镜还是发布母版，零起始半开帧域含起帧、不含终帧。evidence.recipe 指向已运行的入口和收据。拿到母版即可复核画面读法。原片缺失时，将被剪掉的内容、源画面的同帧关系或原声对位标记为待复验。

在拍摄单中写已审机制 ID，按 production 确认制作路径。H3 只编入本镜可拍的布置、表演和摄影。分屏与省略等 CPU 方法按实际收据在后期执行，直接交给 H3 拍摄入口会被拒绝。

## 选择依据

- 首次展示地点规模或系统关系：优先比较近景尺度参照、由近及远亮灯、实体遮挡打开及上下层通道。选择取决于观众需要认识大小、深度、数量，还是因果关系。揭出很多东西并不自动说明这些东西是谁的、为何危险。
- 从看不见到发现有人：比较移动遮挡、擦拭凝露、逆光剪影。辨认身份需要可辨脸部或已建立的服饰道具；剪影只能证明有人及部分姿态。
- 引起警觉：两个来源可区分的光或其他画外线索可让人物改变姿态。画面没有给出持光者时，只能推断有人；低身不等于已经隐蔽，更不等于脱险。
- 进入另一个空间：明确门槛、开门接触、跨入、停看和目的地。暖冷对比或纵深增强吸引力，人物仍需有进入的理由；回忆或幻觉规则需要场面铺垫。
- 检查历史痕迹：纸、凝露、漆等承载面与接触路径必须连续。若揭出的内容不改变人物判断或行动，适合作为过程细节；不要把它优先当作剧情转折。

同一方法可跨作品使用，但必须由当前故事提供上述条件。书名、奖项、题材相近不构成迁移证据。按原著改编时另外核对原文与因果，本库里的原创场面试验不能充当原著事实。

## 把候选写成可拍的镜头

在镜头单中具体填写这几个关系：

| 内容 | 要回答的问题 |
| --- | --- |
| 前置状态 | 哪些人物、物件与空间在首帧已经存在，哪些信息尚被遮挡？ |
| 触发 | 哪个可见动作或可听事件使观众得到新信息？ |
| 不变量 | 哪些几何、材质、光向、持物、人物身份在变化中必须保持？ |
| 可见结果 | 观众实际看到了什么，角色改变了哪个动作或判断？ |
| 后镜责任 | 哪些结论还需要下一镜证明，如身份、开门成功、危险来源或逃离结果？ |

拍摄提示写具体表演和光路；精确遮罩、排字或合成变化进入相应后期工程。当前试片验证了哪部分就继承哪部分；不要把“设计想达到”写成“成片已做到”。参考图取动作发生前的状态，给揭示留出空间与时间。

## 验收与经验更新

先让独立看片者只看媒体，隐藏标题、方法、提示词和预期结论，记录第一遍读到的信息。主审再定位触发前后与可疑处，核对几何、接触、光源、持物和人物反应。先看全段节奏，再按时码精查，不能只用精选静帧通过。

登记当前原片、母版哈希、实际提交回执、采用时段、可观察的结果与限制。未实听的音轨只能记录存在或可解码，不能登记对白、拟音与声画同步通过。试片通过与最终段落通过分开：接入前后镜后仍须复查观众注意点、动作衔接与声音。

失败只修最关键的一项，再按同一条件比较。变化后还要用旧失败例检查该问题是否重现，并用一个不同作品或场景条件复试；没有跨场景复验的条目维持 single-scene-tested。保留独立观察与主审决定，不把一次成功上升为对模型的保证。

后续每轮按相同证据字段更新，已通过镜头替换媒体时重审适用范围和风险判断。网页上的“适用场景”和“容易看成穿帮”供人工补充；自动选用不能替用户填“不会穿帮”。
