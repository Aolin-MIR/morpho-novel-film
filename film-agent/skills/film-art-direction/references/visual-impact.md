# 视觉表现力的设计与审看

## 拍摄或合成之前

1. 先确定这段要让观众感到什么、看出哪种关系，或知道哪件新事。画出承载这一意图的全幅构图；有前后变化时也画出新状态。标出观众先看哪里、哪些视觉元素贯穿全镜、本来看到的世界遵循什么规则。如果要引入非常态，先确定它改变哪个关系、在哪些地方仍遵循正常规则。强几何、色彩、规模或有铺垫的静默也能承载意图。诗性、氛围与主观感知可以由构图、节奏和视点建立，独立看片应能从片段感到预期的情绪或关系。
2. 用整幅画面突出一项主关系；需要变化时做清楚的前后对照。可改变人物与环境的尺度对照、材质的状态或层次、色彩与明暗的支配范围、上下内外的空间关系，或同一事件中两处的时间关系。有转折时，开场给可以认出的基准；变化中保留可追踪的地标、物件、身体部位或同期运动，让观众看见触发和变化之间的联系。
3. 编排机位、人物和景物的相对运动或停留。画出镜头推进、横移、停住或切换时，哪一层先退出、哪部分显露、观众的注意点落到哪里；用同一地标前后的位置与尺度做对照。变化后保留完整可读的一拍。声称推动剧情时，给出可见的行动变化或新的关键信息，并把需要下镜完成的结果写进下镜。
4. 把承载意图的构图、节奏或变化写进实际拍摄提示或合成时间线，分别指定参考素材提供的几何、光位、材质及站位。提交前用实际首帧核对主体数量、材质和动作起始位置，按画面校正提示。白匣被写成布包、两扇隔板被写成三扇，均属提交前发现的输入差异。有触发的段落要给开场和触发单独留出构图。把最不确定的一处做成同片对照，例如保留与裁去尺度参照、停留前后或两种显露顺序，锁定其余条件。

## 看完再登记

独立看片先隐藏标题、制作说明和预期。在原尺寸查看全过程，再用手机显示尺寸重看，保留实际画幅。让看片者描述先注意到什么、感到了什么、哪处构图或节奏引出了这种感受。有剧情作用时，再问读到了什么新信息，以及人物的行动是否因此改变。分别记下两种尺寸下失去的线索。只靠一格截图才能发现时，按时码定位是主形太小、对照太弱、运动带走注意点，还是揭示后停得太短。

| 证据 | 登记内容 |
| --- | --- |
| 基本成立 | 主要构图或视听关系是否可读。有触发时复核连续性、新状态、可用时码和后镜责任。 |
| 视觉显著 | 未见提示的看片者在哪个时刻读出什么鲜明的画面、感受或变化，能否指出形成它的构图、材质或节奏。有剧情作用时登记读到的后果。记录两个观看尺寸的差别和未被读出的信息。 |
| 可迁移 | 在不同题材或场景条件下重做并独立审看，分别记录可替换参数、必需条件和失败边界。单场成片沿用 `single-scene-tested`。 |

保留既有试片和已审方法的证据。以往通过接触、空间或剪辑检查的结果仍按原范围使用；旧片未做视觉显著性审看时，保持该项待查。新样例先记录首看失败、定点修订及修后结果，再依据 [选用与迁移](selection-guide.md) 更新相同机制的证据。

## 已审画面例子

- **《影子先离开》**先给真人和墙影相应的举手姿态，再留在同一画幅看影子独自转向右移。原尺寸能辨手势与轮廓，360 像素宽时主要依靠明墙和大轮廓；细指缘变弱，但仍读到动作分岔与不安。右门内的归宿在两种尺寸下均待确认。
- **《海在头顶》**让冷蓝水下视域在天框内渐露，与暖木阅览室、桌椅和仰视人物同框。360 像素宽时冷暖对照和中后段鱼群可辨，早期窄缝和控制轮盘的手部细节较弱。独立审看有条件通过异质空间并置。可用来建立景观反差，若剧情需要操作或通行，则另拍证据。
- **《中轴渐窄》**同一构图先读到多层通透的矩形开口，再看黑板几乎同步合向中轴。保留左侧亮廊可对照中央黑面，也能看清女子左转。原尺寸和 360 像素宽皆可读。末段实体板并未填满门洞，侧方仍有开口，剧本要求封锁通路时应另拍可核证据。
- **《门落下来成了桥》**竖门封出口，近处深坑断路。扳杆后保持门板的木纹与铁箍，看它翻落成水平通路，并留到角色脚踏木面。360 像素宽仍能读出深坑、亮出口和踏上新路径。可验证人开始使用，是否完整过桥留给后镜。

- **《水花停在柱旁》**首版喷溅后落下，较早冻结的版本在手机尺寸像车停。采用版把水冠成形的瞬间留在柱左，柱右的人和雨继续。360 像素宽仍可比较两边。复跑只绑定本试片原始 H3 及已量测分界、跟踪范围和冻结帧。换场景重新定位实体遮边、测量跟踪区域和冻结时刻，核对原片指纹。
- **《水片立起》**原版只见水平水位上移；第二次 H3 的首帧已露斜水片，之后展开成近竖直水帘。保留白匣下方水平水线，边缘滴水和白沫帮助把水片与硬透明板区分。原尺寸仍有材质歧义，360 像素宽可辨形态变化；启动者和匣的可达性留待另镜。

- 《影手到门边》把既有投影独行的手法接到实体状态的变化。约 2.25 秒影手和包柄与横杆支座重合，约 3.25 秒后门缝收窄，真人仍双手提包，随后转头。横杆起幅已在位，末段门底仍留亮线。若要证明锁门，须另拍闩舌到位或试门受阻。
- 《空椅下沉》将逐段揭示结构改为向下露出方口。外围地板和座椅作固定参照，轴线上的空椅退去后显露灰色高差。持红包的人走到方口，末段伸脚，承重落步与下面通往哪里须另拍。
- 《岔路变红》给两条敞开人行道重新分配同一色带。旧路退红后右路先出现红带，人物才迈入并实际踩在新路上。稳定的石缘、湿砖反光与双拱让路径变化可比，两个出口的实际可达性没有因此被证明发生变化。

## 保留作对照的结果

《纸背的城市》在 0.5–4.75 秒完成连续卷纸与蓝色夜城揭示，独立看片在手机尺寸也读到明显的面积和冷暖变化。但首看仍可解释为普通大窗卷帘开启，本轮保留为基础对照。要表达不可能尺度，另给与近处身体、承载面或物件连续可核验的尺度关系；不要把一个开口后的壮观风景直接命名为尺度异化。

**镜像反例。** 原镜约 0.75–3 秒能读到同貌人物动作不同步，但前景台灯与镜中手的遮挡和接触归属不清，容易读成玻璃两侧的两个人。要用反常镜像，先确定镜框边界、镜内外同一物件的对应及正确遮挡，再改变动作同步；接触错误保留作失效证据。详见 [修订审片记录](method-review.md)。

## 待试场面

- **写实取景。** 船坞维修员俯身摸斜坡边的一段裂缝。排水过后，斜光下银亮的水线退开，露出一道从人脚边直抵高耸船底的黑缝。镜头沿栏杆横移，保持裂缝入画，最后让船壁和斜坡同时形成清晰的形状。维修员看见裂缝横断原路后退向栏杆外的通道。检验同一道裂缝在两种尺寸下是否可追踪，以及是否看得出改道缘由。
- **非常态空间。** 档案库先用完整的地面砖缝与门框建立纵向走道。角色合上一面立式柜门，锁舌咬合时，门框内的远端走道折向上方，门外砖缝与演员脚下仍保持原位。横移让旧路线和新去向同时露出，停看后角色改走画内侧梯。检验触发是否和折转同拍可读，以及保持原位的砖缝能否让观众辨出转折范围。
