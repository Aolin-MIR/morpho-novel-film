# 局部二维艺术合成

从时长和画幅一致的已确认底片开始。需要揭示另一层时，先用门、帘和地面的真实边缘对位。接触和现场声来自底片。以动作或媒介状态触发，将画面变化限定到实际承载面。设定可看懂的起点和稳定的结束状态。

使用仓库 `scripts/render_film_art_2d.py` 的 DSW CPU 执行入口。检查底片指纹、区域范围和时间点。对照出点、中间变化、收镜及实际音轨，再同前后镜播放。保留底片、参数和合成版本。角色身份、手势、人物已经说完的对白、主要物件和地理关系必须仍可识别。

空间主义可用两层材质、带厚度的切口、遮挡、接触阴影和微量视差呈现。故障效果与像素排序的合成必须给出 intent。mode 选 absurd 或 visibly-stylized，setup、trigger、pattern、payoff 分别说明观众先看到的形式、动作触发、视觉规律与叙事后果。试剪时辨认失真是否明确出自设计。样片建立了风格才进入正式合成。

叙事越界可以使用 `scripts/render_metalepsis_study.py` 试取字。底片、透明动作层、词、字体和旁白分别提供。先核查贴近手指的接触，取字前后文意都成立，现场音与下一动作接续。二维试片完成只证明画面机制，表演镜需核对真实动作。

成片的取字让同一演员在完整动作底片里跨过画框。用 `scripts/render_live_metalepsis.py` 按实际原片标出指尖、遮挡和撤回，在真实接触处摆字。跟拍摄景深和比例，保留人脸与肩、肘、腕的动作链。三维感来自材料、光源、受力和遮挡。巨大漂浮手、静止人物和无法标出真实接触的结果只留作反例。用同法检查雨丝、反光、阴影和配乐的触发与收束。

## 叠写的承载面

叠写优先选择同一纸面、门牌或墙纸一角。让观众先认出边缘，再由掀开、擦拭或斜光变化露出原有旧层。前后片对位时锁住建筑接缝、物件位置、光向和无关材质。用同段底片的去效果版做对照；若观者先怀疑接片、材质漂移或纸面受力，收回到更小的承载面重新试。已明确建立主观或非现实规则的场面可以使用更大范围，仍须验证触发和后果可辨。
