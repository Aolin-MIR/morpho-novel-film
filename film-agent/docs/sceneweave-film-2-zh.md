# SceneWeave 2.0 电影台本

Harness 继续负责整片的创作取舍、素材、试拍、审看和定点返修。SceneWeave 2.0 在分镜前完成台本，保留原著定位、可表演的行动、人物选择、结果和对白。分镜用编号调取同一场的文字，台词正文及发声者由台本锁定。每条对白只能分给一个镜头。

普通单场、完整单故事和全书改编共用行动、接触、声音和有意风格化的规则。规则作为版本化文本编入各步骤提示词，运行不需要 Agent 自行发现工具。普通场面可以没有特殊效果。故意越界要有可见起因、持守的物理状态和后果。参考 [film-art-direction](../skills/film-art-direction/SKILL.md)。

宣传片先完整分批阅读，再用 Lotus 的方法决定压缩哪些因果、用哪一处冲突开场和把答案留到哪里。选段、节奏和切点证据形成可检查的顺序。场内声音可以承担重音，留白段保留表演和环境。配乐重音在无对白、无旁白且适合的切口对准实际音乐起势。分镜和声音完成后独立审稿。 [Lotus 项目](https://github.com/DanielWLiu07/Lotus)

## 从实片修订提炼通用方法

| 观察 | 迁入台本的规则 |
| --- | --- |
| 《镜花缘》尾声约 09:50.500 看清接册。文人先托底，白猿随后松手。模糊的后段切回案头。 | 接收方承重、移交方离手、道具运动方向各有可见证据。接镜从同一动作阶段继续。 |
| 《三体》内审稿约 50.500 秒，关闭前盖后才按机顶，听到快门再看黑底片。 | 给观众先建立实验条件，再看操作及结果。物证揭示的声点用本镜可辨触点。 |
| 《五香街》旧取字手比例失真。新稿让实际演员的肩、腕和手指在同一空间内完成，程序按接触点移字。 | 把现实动作和效果的起因分配到各自的生成层。先给尺度、身份、灯光维持的基准，再让叙事结构越界。 |
| 旧版中旁白覆盖可见说话或说话者难辨。 | 台本先写白话交涉，每句绑定一名说话者和一句原文证据。摄影和剪辑再给完整发声和听者反应。 |

新经验以原片时码、正确与错误表现、修复后的证据和适用条件登记。可跨书复验的规则进入 SceneWeave 同一版本的提示词、流程与校验。提示词参与不等于剪入成片，影片来源按实际取用版本登记。

《镜花缘》《三体》的实跑对照经 DSW 的既有 Luna API。两书都从完整原著选段，和现有版本采用同一文字审阅量表。镜花缘基线取现有长版前一分钟，三体基线取现有短剪全段。对照测台本和分镜，成片画面与声音仍要实拍后验收。
