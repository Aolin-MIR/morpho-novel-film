# 长片续制规格

[八部影片制作与验收清单](eight-book-films-acceptance-zh.md)继续决定原著范围、时长、风格、交付和验收。以下改动把发现穿帮的时间前移到拍摄前，并保留每片不同的表现方法。

## 设计和派单

| 环节 | 要落实的内容 | 何时可以继续 |
| --- | --- | --- |
| 事件与剪辑预演 | 原著、人物此刻所知、目标和代价先落到行动。每镜写接过的问题、新增的可见证据和动作窗口。对白先按角色换气和自然停连读一遍。打断、省略和留白由观众所知决定。 | 能仅凭画面和对白理解为何行动、发生什么改变。单故事能独立看到结果。 |
| 参考分工 | 身份用独立清晰的正面或三分之四脸。衣装记底布和层次，地点底图去掉人物，关键道具看材质、体量和持有。大全景可表现比例、关系和环境，微表情及认人交给中近景。 | 脸框使用原图坐标，短边至少 80 px，中心不严重失焦。像素规格只作最低门槛，同人、衣装和实际对焦仍由看图确认。 |
| 同场状态 | 给角色、衣装、道具、门窗、时间等重要对象登记同一组入出状态。交接、落脚、换装、显现要有画内动作及时间。同场相邻镜对照实物状态。远景参考中的人、颜色和装饰不能借作身份。 | 衣装、道具、地理和动作的重置有场景理由。危险镜头优先用已通过参考图的小批量实拍。 |
| 美学变化 | 先建立普通状态，随后给触发动作、变化所在的具体表面、时间和可见后果。意图保留在导演记录，演员在 H3 中做真实动作，局部变化进入独立合成层。 | 观众不读幕后说明也能辨认事件。取字可见手指接触、字随手离开及句意反转。泛化花纹、突然换色和无源飘花退回。 |
| 制作与回传 | 跨机位复用已核实的同一人物、同一底色、同一场景材质。动作接力用真实相位或确认过的原片帧。长拍分到连续可读的动作，不让单次生成同时承担换装、转场、说话和奇观。评估可用秒数和失败原因，同类失败先拆动作或换参考。 | DSW 只用个人工作区和已分配卡。每条真实源片、校验和源帧回传。退件不回流作人物参考。 |
| 混音与口型 | 画内对白由同一位表演者对应原生声音，其他人保持聆听。对白以实际说话人、嘴部起止及转写分别验收。旁白分开安排，不覆盖画内说话。配乐和拟音以真实台词时间窗让位，保留脚步、衣料和室内空气声。 | 看嘴、听词、看剪出点三项都通过。强拟音与原音同声源时只留一个。成片做整段试听和响度检查，单镜不各自推成同样强的声音。 |
| 段落与展厅 | 先以无配乐粗剪确认叙事，再排动机音乐、声桥、标题。关键处给理解时间，重复交代和已读完的尾巴及时削减。完整导出后更新章节、导演字幕及可编辑工程。 | 完整片通过独立观看、源帧范围及音轨检查再晋级，题材、长版或单故事标记准确。 |

## 运行入口

- DSW 新拍批次在 `scripts/dispatch_dsw_film_batch.py` 运行 `--preflight --require-continuity` 后提交。镜头规格写 `contract.continuity`，包含同场编号、`before`、`after`、有动作和时间窗的 `changes`、本镜 `beat`。结构化对白提供 `window`，可按实际句子排核对任务。
- 构图参考标明人物用途。远景比例用 `people: distant`。若构图负责辨认人脸，使用 `people: readable` 及 `face_boxes`。角色素材采用 `people: single` 和单人脸框。场景及道具用 `people: none`，从受污染的参考派生经目视确认的无人物区域。
- 特效填写 `effect` 的建立、触发、承载面、可见结果、时间窗口及 `execution: post`，将触发动作编入 H3 底片提示。合成还要在真实时间轴落实遮挡、落点及声桥。字段齐全只能证明方案可派单。
- 新声音计划走 CPU 剪辑的 `mix` 入口。每镜声明原生对白及来源回执，旁白给实际文件及入点。配乐和拟音窗口跟随本版入出点。剪辑工程带源音、画外音、配乐和拟音信息，导演字幕根据实剪记录。
- 一致性与节奏共同审看。当观众停下来问「这是谁」「东西怎么变了」时，找出由于镜头或声音漏掉的信息。需要强调犹疑时保留等待，明确让它承载人物不敢做什么。素材复用必须保留角色、造型、动作相位与原音出处。

## 参考资料和选取理由

- 采用独立主体与地点参考、清楚起始图、动作提示单一，以及同一机位从合格尾帧延续的做法。应用到 H3 时沿用 H3 自身参考与时长格式。[Runway Gen-4 References](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References) · [Runway 图生视频提示指南](https://help.runwayml.com/hc/en-us/articles/48324313115155-Image-to-Video-Prompting-Guide)
- 把视线、表演动作、服装和镜头节奏写成派单规格。将「听者如何反应」和「说者如何动作」分别设计。节奏依据情节功能和表演，不照搬广告镜长。[Performance Direction Skill](https://github.com/calesthio/generative-media-skills/blob/main/skills/production/creative-direction/performance-direction/SKILL.md) · [Video Plan Skill](https://github.com/agentara/skills/blob/main/skills/aigc/video-plan/SKILL.md) · [Runway 多角色对白](https://help.runwayml.com/hc/en-us/articles/41748090660499-Creating-Multi-Character-Dialogues-with-Act-Two)
- 用主镜建立时间与空间，再从动作中、眼神或明确的声音来源切到反打和特写。剪辑台先看一段对话是否成立，然后排音乐和效果，避免背景声把配乐推来拉去。[DaVinci Resolve 剪辑指南，第 4 课](https://documents.blackmagicdesign.com/UserManuals/DaVinci-Resolve-18-Editors-Guide.pdf?_v=1680159610000) · [Adobe 对白与配乐自动避让](https://helpx.adobe.com/premiere/desktop/add-audio-effects/adjust-volume-and-levels/automatically-duck-audio.html) · [Every Frame a Painting 的表演节奏分析](https://www.youtube.com/watch?v=3Q3eITC01Fg)

## 宣传片怎样开场

| 作品 | 第一拍的冲突 | 声音用在哪里 |
| --- | --- | --- |
| 镜花缘 | 冬夜还合着的花苞，接庭中「花须连夜发」。诏卷脱手后，命令真的被带出去。 | 冷风先建立园中压力，命令用角色同期声，中段让音乐退下。纸声落到交接，低频到下一个切点才进入。 |
| 猫城记 | 坠机后的手撑进碎砂里，撑起来却找不到同行者。观众马上知道外面还有危险。 | 碎砂摩擦和残骸回声先交代近远，随后用画外动静提示危险方位。遇到关键目光和呼吸时拉开空间。 |
| 三国演义 | 降书已经递出去，接受降书的一方仍怀疑来船。两个目的相反的行动逼到同一片江面上。 | 纸声接船板和水声，先让吃水与来向可辨，直到局势变化才加重。 |
| 三体 | 一条可以当场被验证的预期遇到与之冲突的影线。让观众先知道预期是什么，异常随后成为证据。 | 校准时留下风声和操作声。异常到来之前降下其他声音，用单次重音交代观众应该往哪看。 |

开场先做实剪，不只看分镜表。关掉导演说明，用前三秒判断冲突有没有被察觉，再看后面的行动与代价理解是否连得上。使用低频、近场触觉和远场环境时分别写声源、远近、触点及到尾时间。音乐与特效都用实际事件入点，原生对白全程可听，关键声响响过后留出空间。禁止把一声与画面无关的重击当作冲突本身。

[Adobe 预告片剪辑](https://www.adobe.com/creativecloud/video/discover/make-a-video-trailer)提供了基于片种处理节奏和声音的案例。[Adobe 动作及声音匹配剪接](https://www.adobe.com/creativecloud/video/discover/match-cut.html)说明了入点与出点怎样通过画面或声源形成因果。

共用指令在 `film_continuity.PROMOTIONAL_EDITING`，进入 Harness 和 DSW Agent 的短预告、全书宣传片分镜、声音规划及预告审稿。分镜可给 `continuity.beat.impact` 填压力、转折、可见后果及时间窗。时窗必须落在可用动作以内，合法的字段随实际 H3 底片提示编译。当场没有变化时无需分配额外重音。

## 本轮的实际验证

- 素碑参考的 JPG 与旧工程里的场景截图文件指纹相同。匹配旧全书剪辑约 4:21.75 的 H3 远景，两张脸最窄约 19–21 原像素。旧构图只能交代亭、碑和人物比例。已派生无人构图参考，另用唐小山独立脸图拍了 1536×864 反应镜。截取可用前段避开后半段意外张嘴。
- 《认包问父》使用已核对的对白窗口重新混音，新增音乐自动避让，两段对白重新转写均吻合。正式长片仍要逐场复核说话人、嘴部动作、台词入出和前后声场。
- 《催花诏》新开场已剪进十分钟本地审看版。第一拍花苞和冷风进入，命令使用保留的原演员同期，纸声与切点低频独立制作，音乐推迟到台词之后。初版古语存在原音转写差异，已由新版白话原生同期取代。对白取实际完整窗口，混音对句验证，室内风、纸动作和配乐分离。新全书审看为 10:02.375。
- 新镜逐镜登记源图、裁切和回传 SHA。《镜花缘》白猿现已拍到合书和持书翻窗动作。早期补镜的灯笼与重复书道具退出采用；续镜保持同场基准，翻出画框的完整结果仍须纳入后续同场镜头检验。
- 《镜花缘》其余场次的配音及原同期仍须逐项抽离。其他三本已有独立选段，长篇和完整单故事仍在续制。两张 H100 跑批准任务，播放器标题和导演字幕不把补拍样例记成全片完成。

## 风格串入、动作和同期声的追踪

| 问题 | 原因或实证 | 制作中的处理 |
| --- | --- | --- |
| 旧《镜花缘》帆和山门生花 | 旧片单三条航海和入山分镜的 H3 提示中，混入了催花诏的全书配色变化。离岸镜原片帧 24 已见花芽，风暴镜帧 58 可见帆布新增红点，山门镜帧 51 可见石上开始长花。三种生长发生在原生底片。 | 视频与首帧提示分别剥离全片配色进程。局部面材写入对应镜头，只有可定位的光允许移动。旧片仅复用经实帧确认无花且有动作的窗口。 |
| 衣装、动作和道具跳变 | 《女儿国》宫门两脚有白绫。第一条素帆登船补镜的脚掌承重可辨，粉色衣摆和素帆稳定，其中一只脚却成了裸足。 | 锁双足白绫、鞋底接触、重心和下一拍。同一动作的原片只作为运动参考，人物织物和地理由各自图片约束。首版保留为反例，整场未放行。 |
| 原声不完整与错误归属 | 全书当前 263–278 秒实混只剩「你肯认吗」，旧修订单的完整句包含主语与关键物证。旧 480–493 秒实混在「我同你去」后接入另一句的残段。 | 同期台词剪到实际结束，画内出声由镜内本人完成，环境、拟音和配乐分轨。不得给画内不可核对的口型套新对白。有对白需要实话、口部和视线分别通过。 |
| 工艺写进全书仍可能串场 | 早期分镜同时给多个空间写了整部片的配色弧线。生成器可以把前段花朵物化到后段未指定图案的表面。 | 叙事规划可保留全片设计，生产提示只给当前镜头实物。非写实变化由已发生的动作触发，可限定在真实底片的具体表面，由代码接管变化。 |
| 镜头有运动但观众看不懂 | 动态不等于行动。遇到过墙、上船、追逐或说完即切，必须有原片证明动作跨过了正确的边界且后果留在画内。 | 对动作高风险镜使用结构化身体支点与收势，剪点确认可见结果。节奏由前因、观众获得的新信息及人物反应决定，近场触点和真实声源支持冲突转折。 |
