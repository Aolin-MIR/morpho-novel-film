# 散角龙 · 电影 Agent

把中文小说做成有情节的电影。支持从 EPUB 或小说正文创作全书宣传片、完整单故事和长片。

## 支持的功能

- 小说改编、台本创作、导演分镜、人物与场景设定。
- 影片风格选择、视频生成、程序动画、画面合成和剪辑。
- 中文角色对白、旁白、音乐和空间音效。
- 镜头审看、定点返修，以及 MP4 成片与可编辑 OpenFilm 工程导出。

散角龙使用 SceneWeave 进行台本创作，结合 MiniMax H3、其他视频制作工具及美学 Skills 完成影片制作。
